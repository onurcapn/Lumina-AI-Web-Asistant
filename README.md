# Lumina AI Summarizer

Premium AI-powered Chrome extension to summarize web pages or selected text using multiple AI providers (Grok, OpenAI, Gemini, Anthropic).

## 💎 Features
- **Premium Side Panel**: A sleek, glassmorphism side panel that slides in from the right.
- **Multi-AI Support**: Use your favorite AI provider (Grok, OpenAI, Gemini, or Anthropic).
- **Page Summarization**: Get a concise summary of the entire web page content.
- **Selection Summarization**: Select any text on a page and get an instant AI summary.
- **Quick Settings**: Easily switch providers and models directly from the chat interface.
- **Context Menu Integration**: Right-click any selection to summarize via Lumina AI.

## 🚀 Installation
1. Clone this repository or download the ZIP.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select the project folder.

## ⚙️ Setup
1. Click the extension icon in your browser toolbar to open the Lumina Side Panel.
2. Click the **Settings (Gear)** icon in the top right of the panel.
3. Select your **AI Provider** and enter your **API Key**.
4. (Optional) Choose a specific **Model Name**.
5. Save and start summarizing!

## 🛠️ Tech Stack
- **JavaScript (Vanilla)**: Core logic and extension APIs.
- **CSS3 (Modern)**: Glassmorphism UI, transitions, and animations.
- **Chrome Extension API (V3)**: Background service workers, side panels, and storage.
